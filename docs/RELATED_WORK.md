# Related tasks and an honest positioning

PocketRecall has no published benchmark evaluation. We cannot claim SOTA. Its current contribution is an inspectable integration of video observations, persistent 3D evidence, a tool-using voice agent and feedback through a glasses simulator.

| Primary source | Relevant task / idea | PocketRecall comparison |
| --- | --- | --- |
| [LEDGER / Never Look Back](https://ledger-3d.github.io/) | Persistent object histories in 3D from egocentric videos, including objects outside the current view. | Our kitchen demonstration reuses its public video, object outputs and reference geometry. PocketRecall adds the runnable voice/tool/feedback interaction around these records; it does not reproduce or improve LEDGER's benchmark results. Its multi-kitchen demo keeps separate coordinate frames, so it is not evidence of general shared-map relocalization. |
| [EgoRecall](https://3dlg-hcvc.github.io/EgoRecall/) | Streaming egocentric observations and compositional language queries grounded in 3D, restricted to past observations. The project reports 2.25M queries over 183 ScanNet++ scenes; its reported best evaluated method reaches 14.1 F1_full. | Closest future evaluation target for natural-language 3D memory. We do not implement its full language operators, object-instance grounding or evaluation protocol. A successful demo is not a comparable score. |
| [Ego4D episodic memory / VQ3D](https://ego4d-data.org/docs/benchmarks/episodic-memory/) | Retrieve where an object was last seen in egocentric video; VQ3D includes 3D localization from a visual query. | Direct conceptual overlap with last-seen recall. Our typed/spoken category queries and sensor-calibrated desk sample are a different input and setting. |
| [EAGLE, AAAI 2026](https://ojs.aaai.org/index.php/AAAI/article/view/37251) | Unified 2D/3D memory for egocentric visual query localization; the paper reports state-of-the-art results in its evaluated setting. | A relevant memory/geometry baseline, not evidence that our assembly shares its performance. No head-to-head experiment has been run. |
| [ESOM](https://arxiv.org/abs/2411.16934) | Online egocentric streaming object memory for visual query localization. | Relevant to keeping a searchable object history without rescanning the entire past. Our limited category registry is not a replacement for its object discovery/tracking system. |

The product-oriented distinction is the complete interaction loop: video → auditable spatial memory → voice tool call → direction/tap/heartbeat. The research question is whether that memory and grounding remain correct across long sequences, similar instances, map drift, occlusion and return visits. The current real sample cannot answer that question.

Before making a performance claim, freeze a benchmark protocol and report localization accuracy/F1, identity errors, temporal leakage, pose/depth assumptions, memory size, latency and failures. Compare identical splits and query inputs against the corresponding baselines, with ablations for geometry source, instance tracking and agent routing. Separate ground-truth geometry results from estimated geometry results.
