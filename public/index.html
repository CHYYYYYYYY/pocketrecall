One key. A real-world memory.

The sandbox works now without credentials. Live camera analysis uses Gemini, with the key kept on your local server.

  1. Create an API key in Google AI Studio ↗.
  2. Copy .env.example to .env.local.
  3. Set GEMINI_API_KEY and an available GEMINI_MODEL.
  4. Restart npm start, connect your camera, and optionally calibrate the desk.
Camera permissions and voice recognition require localhost or HTTPS. Demo data is synthetic; live mode never silently falls back to it.
